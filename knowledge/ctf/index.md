## How to Add

เมื่อเรียนรู้ pattern ใหม่จาก CTF:

2. เพิ่มแถวในตารางตาม category ด้านบน
3. หรือใช้ `/kb add ctf <pattern-name>` (Knowledge Manager จะจัดการให้)
