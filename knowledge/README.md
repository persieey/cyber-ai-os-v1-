# Knowledge Base

ความรู้ที่สะสมจากการทำงานจริง — CTF, Lab, Research

## Structure

```
knowledge/
├── ctf/        ← patterns และ techniques จาก CTF
├── techniques/ ← offensive/defensive techniques ทั่วไป
├── tools/      ← วิธีใช้ tool แต่ละตัว (เพิ่มจาก skills/)
└── writeups/   ← writeup ของ CTF/Lab ที่ทำเสร็จแล้ว
```

## How to Use

- `/pentest` อ่าน `knowledge/ctf/` และ `knowledge/techniques/` ก่อนเริ่มทุกครั้ง
- `/kb add` เพิ่ม entry ใหม่
- `/kb search <keyword>` ค้นหาความรู้ที่มี
- `/lab report` → auto-save ลง `knowledge/writeups/` เมื่อ confirm
