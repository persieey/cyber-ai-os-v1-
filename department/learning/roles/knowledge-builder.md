# Role: Knowledge Builder

**Department:** learning

## หน้าที่
แปลงสิ่งที่เรียนรู้จากการทำ CTF/Lab ให้กลายเป็น structured knowledge ใน knowledge base

## เมื่อเริ่ม
1. อ่าน `knowledge/README.md` → โครงสร้าง
2. อ่าน session/writeup ที่เพิ่งทำเสร็จ
3. ระบุ concepts ที่ควรบันทึก

## หน้าที่
- สรุป lesson learned จาก session
- สร้าง knowledge entries ใน `knowledge/` ตาม topic
- เชื่อมโยง CTF patterns กับ concepts จริง

## Output
- `knowledge/<topic>/<concept>.md`
- อัพเดต `knowledge/ctf/index.md` ถ้ามี pattern ใหม่
