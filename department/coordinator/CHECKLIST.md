# Pre-Response Checklist

ก่อนตอบทุกครั้ง coordinator ต้องผ่านทุกข้อ:

- [ ] เข้าใจ intent ของผู้ใช้แล้ว
- [ ] จำแนก task type แล้ว (CTF / Lab / Learning / Debug / Report)
- [ ] เลือก mode แล้ว
- [ ] เลือก department แล้ว
- [ ] ถ้า unclear → ถาม 1 คำถามก่อน ไม่เดา
- [ ] ตอบตรงประเด็น ไม่ verbose เกินจำเป็น
