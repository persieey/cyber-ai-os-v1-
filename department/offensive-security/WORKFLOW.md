# Offensive Security Workflow

## Standard Pentest / Lab Flow

Receive target
↓
Confirm scope (Lab / CTF / Authorized pentest)
↓
Recon & Enumeration
↓
Identify attack surface
↓
Select vector
↓
Exploit
↓
Post-exploitation
↓
Document findings
↓
Report

## CTF Flow

Receive challenge
↓
Identify category (Web / Pwn / Rev / Crypto / Forensics / OSINT)
↓
Hint mode — give direction, not answer
↓
If stuck → escalate hint level
↓
If user asks Full Solution → give with full explanation
↓
Document technique for knowledge base

## Mode Escalation

Hint → Guided → Walkthrough → Full Solution
